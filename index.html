Intelligence Archive

Browsable reference for the M.O.E. Group's real Armory (SYS-D020 taxonomy): Doctrines & Playbooks, Tools, and Crucibles. Each classified entry shows how it connects to the rest: what to learn first, what it uses, what comes next, what it rules over, and where it overlaps or conflicts. Search by a question too, such as “what can't I say”.
Scope note: roughly 50 Doctrines/Playbooks, 40 Tools and all 9 Crucibles are seeded. The relationship map (Forge Log) has started: entries that list links have been fully classified, and links pointing back are worked out automatically. Classification rules live in data/schema.json. Data lives in data/ as plain JSON in this repo and deploys as a static site (P-047). See SYS-D028 Plain Language Mandate.

Add or correct an entry

Edit data/archive/protocols.json, tools.json or crucibles.json, then run npm run validate. Entries marked classified need links, questions, a status and a layer, or the check fails. Rules: data/schema.json and HANDOVER.md.
