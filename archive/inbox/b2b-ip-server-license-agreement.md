**Classification:** B2B INFRASTRUCTURE CONTRACT ARCHITECTURE
**Governance:** The M.O.E. Group / Sovereign Protocol
**Objective:** Permanently separate One-Time Intellectual Property (IP) Deployment from Ongoing Server Hosting and Management Retainers. Eliminate "unwritten trust" and prevent clients from confusing software tools with free administrative labor.

---

### SECTION 1: DEFINITIONS & SCOPE OF DEPLOYMENT
1.1 **Proprietary Intellectual Property (The Seed):** All frontend interfaces (Vercel deployments), backend logic gates (Supabase, Make.com webhooks), and operational consoles (M.O.E. Terminals) remain the absolute, unalienable property of the Architect.
1.2 **The Deployment Package (One-Time License):** Refers to the initial configuration and hand-off of structural UI/UX code, qr-code frames, and diagnostic frameworks. 
1.3 **Server Infrastructure & Maintenance (The Retainer):** Refers to ongoing cloud database hosting, API webhook maintenance, SSL management, and live telemetry data-hydration.

### SECTION 2: THE HOSTING & RETAINER MANDATE (THE ZERO-CLAUSE GAP FIX)
2.1 **The Separation of Powers:** Code deployment does not grant perpetual free server hosting or uncompensated management labor. 
2.2 **The Monthly Service Level Agreement (SLA):** Ongoing operational access to cloud databases and automated webhook pipelines requires an active, non-cancellable monthly infrastructure retainer (agreed upon prior to deployment).
2.3 **Non-Payment Protocol (The Sunset Clause):** In the event of invoice stagnation (e.g., past 30 days), the Architect reserves the absolute right to execute an automated remote server sunset. Database access, API payloads, and frontend terminal routes will be suspended instantly until the ledger hits a zero balance.

### SECTION 3: THE HANDOVER & BOUNDARY ENFORCEMENT
3.1 **Zero Free Labor Rule:** Brick-and-mortar operational support (such as graphic adjustments, manual data entry, or floor management) is strictly excluded from software licenses. Any expansion of operational scope requires an explicit, pre-paid consulting addendum.
3.2 **The Burden of Proof:** The client acknowledges that server optimization and data integrity depend entirely on active financial compliance. A delayed payment queue results in an immediate suspension of technical support.
