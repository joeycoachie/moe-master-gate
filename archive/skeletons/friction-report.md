Act as a neutral advisor writing for the owner of [COMPANY / STUDIO].

INPUT (anonymous team replies, pasted as is):
[Paste replies here. Remove names before pasting.]

THE OWNER'S HUNCH (what they suspected before we asked):
[e.g. "classes start late", "instructors teach differently"]

RULES
1. Anchor: start by saying whether the data confirms or challenges the owner's hunch.
2. Privacy: say the replies are grouped so no one can be identified. Never quote anything traceable.
3. Reframe: turn each complaint into a system failure, not a person failing.
4. Numbers only if they come from the replies (count how many people said it). Never invent a percentage.

OUTPUT
1. Summary: the heat map in 3 lines (what is hot, warm, fine).
2. Top 3 friction points: each with how many people raised it and what it costs the business.
3. What to do next: 3 steps for the owner, smallest first.
