CLIENT: [name] · START: [date] · 90-DAY GOAL: [one number, e.g. revenue, leads, retention]
OWNER ON OUR SIDE: [name]

PHASE 1 · STABILISE (weeks 1-2)
[ ] Agree the Friday report with the client (what we send, when)
[ ] One tracker for all their data (leads, sales, clients): [link]
[ ] Audit their channels: what works, what leaks: [link to report]
[ ] Fix the first impression (profile, bio, booking path)

PHASE 2 · BUILD (weeks 3-4)
[ ] Content plan: 2-3 core topics + weekly short posts
[ ] First 2-week content calendar
[ ] Simple lead-to-client steps written down (who replies, how fast, what they say)
[ ] Client signs off the 90-day plan

PHASE 3 · RUN (weeks 5-12)
[ ] Weekly content live
[ ] Pipeline worked toward the goal, tracker updated weekly
[ ] Weekly lesson: one thing that went wrong, run through the Crucible Investigator
[ ] Turn each big lesson into a written playbook for the client
[ ] Friday report: numbers, the lesson, the new playbook
[ ] Day 90: final after-action report against the goal

FRIDAY REPORT (every week)
1. Numbers: [leads] [conversion %] [revenue]
2. The lesson this week: [one paragraph]
3. New playbook added: [name]
