## The rule

Every software deal has **two separate prices**. Code is not free hosting, and a tool is not free admin labour.

| Line | What it covers | Price |
|---|---|---|
| **1 · Build fee** (one-time) | Setting up and handing over the screens, QR pages and diagnostic frameworks | **RM 5,000** (P-048) |
| **2 · Monthly hosting and upkeep** | Database hosting, webhooks, security certificates, live data | Agreed before the build starts |

## The terms

1. **Hosting pauses if unpaid.** More than 30 days overdue: database, webhooks and terminal links pause until the balance is cleared.
2. **Code stays ours.** The client gets a licence to use it, not ownership.
3. **Scope wall.** Floor work, graphics and manual data entry are not in the licence. Extra scope needs a paid add-on agreed first.
4. **Parked: RM 1,500 one-time handover.** The code is handed over once, and the client pays their own servers. Offer only if a client refuses any monthly fee.
